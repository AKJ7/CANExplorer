# Links

## Libraries

- [python-can](https://python-can.readthedocs.io/): interfaces, log files. In particular
  [SocketCAN and virtual CAN interfaces](https://python-can.readthedocs.io/en/stable/interfaces/socketcan.html).
- [cantools](https://cantools.readthedocs.io/): DBC, KCD, SYM and ARXML databases.
- [ldfparser](https://pypi.org/project/ldfparser/): LIN description files.
- [qasync](https://github.com/CabbageDevelopment/qasync): Qt and asyncio on one event loop.
- [PyQt6](https://www.riverbankcomputing.com/static/Docs/PyQt6/) and [Qt Quick](https://doc.qt.io/qt-6/qtquick-index.html).

## Buses and protocols

- CAN FD set-up and background: [CAN FD](https://munich.dissec.to/kb/chapters/can/canfd.html).
- [linux-lin / sllin](https://rtime.felk.cvut.cz/gitweb/linux-lin.git): LIN drivers for Linux.
- [BUSMASTER](https://github.com/rbei-etas/busmaster): origin of the DBF database format.
- [odxtools](https://github.com/mercedes-benz/odxtools): ODX diagnostic descriptions (successor of CDD in cantools).

## Standards

- ISO 11898: CAN and CAN FD.
- ISO 15765-2: ISO-TP transport protocol.
- ISO 14229-1: Unified Diagnostic Services.
- ISO 17987 / LIN 2.x: Local Interconnect Network.
- SAE J1939: heavy-duty vehicle networks.
- CiA 301: CANopen application layer.
- SAE J2012: diagnostic trouble code notation.
