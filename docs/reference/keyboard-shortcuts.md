# Keyboard shortcuts

Shortcuts follow the conventions of the platform; on macOS use ++cmd++ instead of ++ctrl++.

| Shortcut | Action |
|---|---|
| ++ctrl+n++ | New connection |
| ++ctrl+o++ | Replay a log file |
| ++ctrl+w++ | Close the current connection |
| ++ctrl+c++ | Copy the selected rows |
| ++ctrl+a++ | Select all rows |
| ++ctrl+f++ | Find in the trace |
| ++enter++, ++f3++ / ++shift+f3++ | Next / previous match |
| ++ctrl+b++ | Bookmark the selected trace rows, or remove their bookmarks |
| ++ctrl+shift+o++ | Open a workspace |
| ++ctrl+s++ | Save the workspace |
| ++ctrl+shift+s++ | Save the workspace as another file |
| ++ctrl+comma++ | Preferences (where the platform defines this shortcut, e.g. macOS) |
| ++ctrl+q++ | Exit |
| ++enter++ | In the transmit fields and the raw diagnostic request: send |
| ++shift++ / ++ctrl++ + click | Extend the row selection |
